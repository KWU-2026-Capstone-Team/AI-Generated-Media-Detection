## 0. 하루 요약 (무슨 일이 있었나)

```
가설 A "FaceSwap은 고주파 부호가 반대다"           → 반증 (모든 조작이 고주파 감소)
가설 B "FaceSwap 흔적은 경계 seam에 숨어있다"       → 반증 (FaceSwap seam이 오히려 최소)
   └ 종합: FaceSwap = 4개 저수준 지표 전부 최소 = "가장 조용한 조작"
가설 C "압축이 저수준 흔적을 지운다(→게이트 필연)"   → 반증 (JPEG는 보존, 해상도손실만 감쇠)
   └ 재검증: Δ(평균차이)는 붕괴로 보였으나...ㅣ
가설 C' "해상도 손실이 판별력을 파괴한다"           → 반증 (효과크기·AUC는 보존, Δ는 분산착시)
   └ 부수 발견: seam은 Deepfakes 전용 특징이었다
가설 D "FaceSwap=0.52=저수준에 완전히 눈멂"         → 과장 (잔차 핸디캡. RGB 모델은 0.604, NT도 0.55)
   └ 정정: DF는 쉽고(~0.8), FS·NT는 어렵다(~0.55-0.60)
진행중 E "저수준 '일반'의 한계인가, 내 구현의 한계인가" → SBI 공정 baseline 학습중
```

**방법론 교훈 3개가 이날의 진짜 수확:**
1. **분산을 무시한 평균차이(Δ)는 판별력의 프록시가 아니다** — 효과크기(Cohen's d)/AUC로 봐야 한다.
2. **n=4 상관계수는 outlier 하나가 만들 수 있다** — seam↔난이도 "단조 관계"는 DF 한 점이 만든 착시였다.
3. **"저수준이 안 된다"를 주장하려면 저수준 *특화* 방법(SBI)으로 공정하게 반증 시도해야 한다** — 비특화 분류기의 한계일 수 있다.

### 실험 1 — 고주파 부호 실험 (`hf_sign_probe.py`)

**질문:** FaceSwap의 cross-manip 역전(AUC 0.363)이 "고주파 부호 반대" 때문인가?
가설: learned(DF/NT)는 노이즈 주입→고주파↑, graphics(FS)는 렌더링 평활화→고주파↓.

**방법:** 페어드 비교(fake vs 그 소스 real, 같은 프레임) + 얼굴 중앙 70% + 비디오 단위 집계(400비디오/기법).
지표 3개: 라플라시안 분산, 방사스펙트럼 고주파대역, 고주파/저주파비.

**결과 (fake−real 중앙값):**

| method | Δlap_var | Δhf_ratio | 부호 | cross-AUC |
|---|---|---|---|---|
| Deepfakes | −13.60 | −0.0050 | − | 0.729 |
| NeuralTextures | −8.58 | −0.0051 | − | 0.549 |
| Face2Face | −5.41 | −0.0005 | − | 0.628 |
| **FaceSwap** | **−2.00** | +0.0009 | − | **0.363** |

**판정: 가설 반증.** DF/NT가 `+`일 거란 예측과 달리 **4기법 전부 `−`**(고주파 감소). FaceSwap은 부호가 반대인 게 아니라 **변화량이 압도적으로 작음**(DF의 1/7). → "FaceSwap은 가장 텍스처를 보존하는 조작."

### 실험 2 — 경계 seam 실험 (`hf_boundary_probe.py`)

**질문:** FaceSwap 흔적이 내부가 아니라 **합성 경계(seam)**에 있나?

**방법:** 내부(r<0.45) vs 경계링(0.5<r<0.85)의 국소 고주파. `seam_score = Δ경계 − Δ내부`.

**결과:**

| method | seam(lap) | seam(hp) | cross-AUC |
|---|---|---|---|
| Deepfakes | **+0.611** | +0.541 | 0.729 |
| Face2Face | +0.121 | +0.114 | 0.628 |
| NeuralTextures | +0.021 | +0.018 | 0.549 |
| **FaceSwap** | **+0.061** | +0.027 | 0.363 |

**판정: 가설 반증.** FaceSwap seam은 Deepfakes의 **1/10**. 경계에도 흔적이 최소.

**실험 1+2 종합:** FaceSwap은 **내가 잰 4개 저수준 지표(내부 lap_var, 내부 hf_ratio, 경계 seam_lap, seam_hp) 전부에서 최소값**.
→ *"FaceSwap이 어려운 건 부호가 반대여서도 흔적이 숨어서도 아니라, 저수준 흔적을 가장 적게 남기는 가장 조용한 조작이기 때문."*
(단, n=4 상관계수는 약증거. 견고한 건 "FS가 일관되게 바닥, DF가 일관되게 최상"이라는 패턴. → **실험 7에서 이 상관 해석이 뒤집힘**)

### 실험 7 — 효과크기 (`effect_size.py`) ⭐ 이날의 전환점

**질문 (사용자 caveat):** Δ가 커져도 분산이 함께 커지면 판별력은 안 오른다. **Δ는 AUC의 프록시가 아닐 수 있다.**
per-image seam을 점수로 fake/real을 직접 분리 → **단일특징 AUC + Cohen's d**(분산 반영).

**결과:**

| method | none (d / AUC) | jpeg20 | blur1.0 | scale3 |
|---|---|---|---|---|
| **Deepfakes** | 0.564 / **0.712** | 0.565/0.708 | 0.547/0.699 | 0.517/**0.661** |
| Face2Face | 0.186/0.547 | .../0.545 | .../0.548 | .../0.536 |
| FaceSwap | 0.045/0.547 | .../0.549 | .../0.549 | .../0.550 |
| NeuralTextures | −0.007/0.497 | .../0.493 | .../0.496 | .../0.498 |

**판정: 가설 C' 반증 + seam 재해석.**
- **Δ 붕괴는 분산 스케일링 착시였다.** DF scale3: 평균차이 0.707→0.150(21%)인데 pooled_std도 1.25→0.29(23%)로 같이 붕괴 → **d/AUC는 유지**(0.712→0.661, 93%). 블러/스케일은 분포를 통째로 축소할 뿐 판별력은 안 죽임.
- **seam은 Deepfakes 전용 특징.** 단일특징 AUC가 DF만 0.71, F2F/FS/NT는 clean에서도 0.50~0.55(≈우연).
  → 실험 1·2의 "seam 순서 = AUC 순서, 상관 +0.73"은 **단조 관계가 아니라 DF 한 점(outlier)이 만든 상관**이었음.

**폐기:** ① Δ 기반 해상도 붕괴 서사 ② "저수준 흔적 크기 → 난이도" 단조 법칙.

### 실험 9 — SBI 공정 baseline (`scripts/train_sbi_baseline.py`) ⭐ 아키텍처 결정

**질문:** 저수준 *특화·일반화 설계* 방법(SBI=Self-Blended Images)은 FS·NT를 잡나?
APP/SRM은 비특화 강분류기라, "저수준이 안 된다"를 결론내기 전 공정한 반증 시도 필요.

**설계:** 원본만으로 self-blend pseudo-fake 생성(조작 하나도 안 봄) → 표준 ConvNeXt 학습 → 4기법 각각 테스트.
component split 유지. self-blend 검증 통과(픽셀차이 2.5~5.2, seam 대부분 증가 = 경계 아티팩트 생성).
DF honesty gate 통과(모든 fold ~0.78–0.83) → SBI-lite 유효.

**결과 (5-fold 평균 ± std) — 세 방법 나란히:**

| held-out | APP(외형) | SRM(잔차) | **SBI(blending)** | 최적 |
|---|---|---|---|---|
| Deepfakes | 0.822 | 0.782 | 0.798 ± .02 | APP |
| Face2Face | 0.663 | 0.652 | 0.534 ± .02 | APP |
| **FaceSwap** | 0.604 | 0.524 | **0.644 ± .04** | **SBI** |
| NeuralTextures | 0.550 | 0.572 | **0.480 ± .02** | SRM |

(주의: 2-fold 중간결과에서 FaceSwap이 0.545 vs 0.734로 튀었으나 5-fold에서 0.644로 수렴. → cross-manip 분산이 커서 소수 fold 신뢰 금물, 실험 8 숫자들도 오차막대 있음.)

**판정: (A)도 (B)도 아닌 (C) 상보성.**
- **(A) "SBI도 FS 못 잡음" 반증:** SBI FaceSwap 0.644 = 셋 중 최고. blending 특화가 실제로 FaceSwap을 도움(얼굴 paste라 경계 존재). → **"저수준이 FaceSwap에 구조적으로 눈멀었다"는 thesis 폐기.**
- **(B) "SBI가 답" 반증:** SBI는 F2F(0.534)·NT(**0.480, chance 이하**)에서 무너짐. blending 특화가 경계 약한 조작(표정·텍스처)엔 역효과.

**진짜 발견 — 조작 계열마다 최적 탐지기가 다르다:**
```
FaceSwap  (그래픽 paste, 경계 O)      → blending(SBI) 0.644
Face2Face (표정 재연, 경계 약)        → 외형(APP) 0.663
NeuralTex (신경 텍스처, 경계 거의 X)  → 아무도 못 잡음(0.48~0.57), SBI 역효과
Deepfakes (GAN swap, 경계+아티팩트)   → 다 잘(~0.8)
```
- **어떤 단일 탐지기도 4계열을 다 못 잡음.**
- **가장 조용한 건 FaceSwap이 아니라 NeuralTextures** (SBI 0.480 = chance 이하). 아침 seam(NT 0.021)이 예고.
- 상보 이득은 **작음**(FS 0.604→0.644, +0.04). cross-manip 숫자 자체가 mediocre(최고 0.66).

## 3. 종합 — 이날 끝의 상태

### ✅ 확정 (견고)
- **방법론:** component split이 신원 누수를 0으로 만들며 이전 strict split의 지표 부풀림을 고침.
- **cross-manip 난이도 구조:** DF 쉬움(~0.8) ≫ F2F 중간(~0.66) > FS·NT 어려움(~0.48–0.64).
  세 독립 방법(APP·SRM·SBI)이 큰 그림 일치.
- **조작 계열마다 최적 탐지기가 다르다 (상보성):** FaceSwap→blending(SBI 0.644),
  F2F→외형(APP 0.663), NT→아무도 못함(≤0.57, SBI는 0.48로 역효과), DF→전부(~0.8).
  **단일 탐지기로 4계열 커버 불가.**
- **가장 조용한 조작 = NeuralTextures** (경계 거의 없음, SBI가 chance 이하). FaceSwap 아님.
- **seam은 Deepfakes 전용 특징** (단일특징 AUC: DF 0.71, 나머지 ~0.5).
- **저수준 판별력은 열화(JPEG·블러·스케일)에 대체로 강건** — Δ가 아니라 효과크기로 보면 그렇다.

- "FaceSwap은 고주파 부호가 반대다"
- "FaceSwap 흔적은 경계 seam에 숨어있다"
- "저수준 흔적 크기가 탐지 난이도를 단조적으로 결정한다" (outlier 하나가 만든 상관)
- "압축/해상도 손실이 저수준 신호를 파괴한다" (Δ 분산 스케일링 착시)
- "FaceSwap = 0.52 = 저수준에 완전히 눈멂" (잔차 핸디캡 + NT도 동급으로 어려움)
- **"저수준이 FaceSwap에 구조적으로 눈멀었다 → semantic(CLIP) 브랜치 필요"** (SBI가 FS 0.644로 최고 → blending으로 잡힘. 필요한 건 semantic이 아니라 blending 브랜치)

### ❓ 미지 (다음 과제)
- 학습된 CNN이 F2F에서 뭘 보고 0.66을 내나? (seam은 F2F를 설명 못 함 → 미세텍스처? 색통계?)
- **NeuralTextures를 뭘로 잡나?** (모든 저수준·blending 방법이 ≤0.57. 진짜 남은 hard case)
- 열화 하에서 *학습된 모델*의 AUC는? (seam은 coarse — 미세텍스처는 다를 수 있음. 실험 7이 답 못 함)
- 공식 landmark 기반 SBI면 FS·NT가 더 오르나? (SBI-lite는 타원 mask 근사)

## 4. 정정된 thesis (현재 최선의 형태)

> **초기:** "저수준 흔적 크기가 난이도를 결정하고, 압축이 그걸 지운다."  → *대부분 반증*
>
> **확정 (실험 9 이후):** "FF++ cross-manipulation에서 **조작 계열마다 최적 탐지 패러다임이 다르다.**
> FaceSwap(그래픽 paste)은 blending 탐지기가, Face2Face(표정 재연)는 외형 탐지기가 가장 잘 잡으며,
> NeuralTextures(신경 텍스처)는 셋 다 못 잡는다(≤0.57). 어떤 단일 탐지기도 미지 4계열을 다 커버하지 못하므로,
> **외형(APP)+blending(SBI)의 상보 결합**이 단일 분류기보다 넓게 커버한다. (단, cross-manip 상보 이득은 작음 +0.04;
> 배포용 분류기는 4기법 다 학습한 in-dist 모델(~0.92)이 본체.)"

**함의:** 아키텍처는 "저수준+semantic(CLIP) 게이트"가 아니라 **"외형+blending 앙상블"**. CLIP은 불필요(FS는 blending으로 잡힘).
차별점은 "누수 없는 프로토콜에서 조작 계열별 탐지기 상보성을 정량화"라는 측정 기반 분석 기여.

## 5. 방법론 교훈 (재사용 가능한 것)

1. **평균차이 ≠ 판별력.** 분산이 함께 변하면 Δ는 오도한다. 항상 Cohen's d 또는 AUC로 검증.
2. **작은 n의 상관은 outlier를 의심.** 점별로 찍어 단조성 확인. (seam↔난이도가 이걸로 무너짐)
3. **"내 방법이 안 된다" ≠ "그 부류가 안 된다".** 반증엔 그 부류의 *특화·SOTA* 방법으로 공정 시도.
4. **프록시는 실제로 검증.** seam(coarse) 하나로 학습모델 AUC를 예단하지 말 것 → 학습모델 직접 측정.
5. **의심되면 no-op부터 검증.** (실험 5) 빨리 끝난 실험은 픽셀차이·처리량으로 실재 확인.

## 실험 10 — ST-SBI 시간축 프로브 (temporal incoherence)

**가설:** 딥페이크 얼굴은 생성기가 매 프레임 새로 그려 "P/B 예측 세계 속 all-intra 섬" =
시간적으로 예측 불가 → 얼굴 영역 시간 잔차가 배경 대비 상승.

**방법:** 디코더 전용 2차 시간잔차 `r2 = |f_t − ½(f_{t−1}+f_{t+1})|`(선형 모션 제거).
특징 = `log2(face_r2 / bg_r2)`의 fake-vs-real AUC. real/fake는 프레임 정렬, bbox 공유.
**Positive control:** `|fake−real|` 조작 footprint face/bg = 2.6~9.4× (전 기법 통과).

**결과 (AUC):**

| 변형 | DF | F2F | FS | NT |
|---|---|---|---|---|
| 얼굴 평균 | 0.524 | 0.476 | 0.561 | 0.458 |
| 픽셀 p95(국소) | 0.510 | 0.467 | 0.557 | 0.461 |
| **입 영역**(NT/F2F 조작 위치) | 0.461 | 0.461 | 0.569 | **0.432** |

**판정: 반증.** 전부 우연 근처. 핵심 — "입 주변만 조작이라 얼굴 평균에 희석됐다"는 구제 가설을
**직접 반박**: 실제 조작 위치(입)에서 재니 NT 반전이 **더 커짐**(0.458→0.432, CI가 0.5 아래로 배제).
fake 얼굴이 real보다 시간적으로 **더 매끄러움**("over-smooth 섬", 가설의 정반대). FaceSwap(0.57)만
미약 정방향인데 FS는 이미 SBI로 잡히는 케이스. 메커니즘: 생성 파이프라인의 시간 안정화 +
NT(텍스처)·F2F(워핑)는 "매 프레임 새로 그림"이 아님.

## 실험 11 — 공간 압축 이력 프로브 (blockiness + DCT 이중양자화)

**가설:** 얼굴은 생성기·다른 QP를 거쳐 배경(native c23)과 압축 이력이 다르다 → 격자/양자화 지문 차이
(CAT-Net식). 시간 안정화로 안 지워지는 성질.

**Probe A (blockiness):** 8×8 블록 경계 에너지 − 블록 내부 에너지, `face−bg` diff의 fake-vs-real AUC.

| 영역 | DF | F2F | FS | NT |
|---|---|---|---|---|
| 얼굴−배경 | 0.464 | 0.479 | 0.436 | 0.479 |
| 입−배경 | 0.389 | 0.378 | 0.411 | **0.352** |

**Probe B (DCT 이중양자화):** 저·중주파 AC 계수 히스토그램의 FFT 주기성 피크(양자화 comb 강도 =
진짜 압축 이력 지문). + 대조군 `acZeroRatio`(스무딩 echo).

| 특징 | DF | F2F | FS | NT |
|---|---|---|---|---|
| **comb 얼굴/bg** | 0.503 n.s. | 0.493 n.s. | 0.516 n.s. | 0.514 n.s. |
| **comb 입/bg** | 0.517 n.s. | 0.510 n.s. | 0.490 n.s. | 0.457 n.s. |
| *(대조) zero 입/bg* | **0.641** | 0.531 | 0.510 | **0.576** |

**판정: 반증 (airtight).** comb(진짜 DQ 신호)은 전부 우연. 반면 **같은 DCT 파이프라인이 스무딩
신호는 유의하게 잡음**(DF-입 0.641, NT-입 0.576) → 프로브가 둔한 게 아니라 **압축 comb 신호 자체가
실물에 없음**을 증명. blockiness는 오히려 반전(fake가 더 매끄러움, flip 0.59~0.65) = 압축 격자가
아니라 스무딩. c23 in-loop deblocking + 재인코딩이 압축 이력을 균질화. "리뷰어가 진짜 압축 신호(DCT)는
안 봤다고 할 여지"까지 닫음.

## 실험 12 — 압축 challenge-response 곡선 프로브 (학습 없음)

**가설:** 정적 점수가 아니라 **재압축에 대한 점수 응답 곡선**이 신호. real은 위조 신호가 없어 평평,
fake는 위조 신호가 압축에 뭉개져 붕괴 → 낙폭 Δs가 특징.

**설정:** 학습 없이 기존 APP 체크포인트(`direct_c23_face_rgb`, ConvNeXt-tiny, in-dist 5-fold)를
**각 비디오의 held-out fold로 채점(신원 누수 0)**. 조건 = c23(h264)/c37(mpeg4)/crf28(hevc, 부분 53쌍).
**크롭 검증:** c23 baseline AUC DF 0.920·F2F 0.888·FS 0.915·NT 0.780 (Haar 크롭으로도 탐지기 정상).

**Positive control — 실패:** fake 점수가 압축에 안 떨어짐. Δ37(c23−c37) = DF −0.021(p.53),
F2F −0.004(p.92), **FS +0.050(p.03, 유일 유의)**, NT −0.013(p.76). crf28(hevc)로 세게 걸어도 무하락.
→ fake 신호가 압축에 **강건**(실험 4~7 "저수준은 열화에 강건"과 일치). 대전제가 뿌리에서 틀림.

**궤적(`scratchpad/exp12_trajectory.png`):** real 바닥에서 평평(0.064→0.100→0.096), fake 위에서 평평.
**수렴·교차 없음.** 정적 격차가 압축 내내 보존 → 기울기(Δ)엔 여분 정보 없음.

**AUC 판정 — combined < static, 4기법 전부:**

| method | static s(c23) | delta Δ37 | combined [s,Δ] 5-fold OOF | comb−stat |
|---|---|---|---|---|
| DF | 0.920 | 0.562 | 0.907 | −0.012 |
| F2F | 0.888 | 0.615 | 0.837 | −0.051 |
| FS | 0.915 | 0.651 | 0.833 | −0.082 |
| **NT** | **0.780** | 0.548 | **0.690** | **−0.090** |

**판정: NO-GO.** delta는 단독 미약 신호(0.55~0.65)지만 static보다 훨씬 약·노이즈라 결합 시 성능을 깎음.
NT 이득 −0.090 = 이 방향의 존재 이유가 무너짐. **정직한 유보(스펙 준수):** positive control이 실패했으니
엄밀히는 "디스크의 재압축(mpeg4/hevc)이 fake 신호를 붕괴 못 시킴"을 보인 것. 더 센 교란(c40·강블러·
다운스케일)이 유일한 미검증 레버지만, (a) hevc도 이미 안 먹혔고 (b) 실험 7이 열화 강건성을 확립 →
결론 불변으로 예측.

# Part 2 — CLIP 배터리 · NT 벽 · temporal 돌파 (2026-07-09 오후~밤)

Part 1이 "저수준·외형이 FS/NT에 약하다"까지 왔다. Part 2는 **① 강한 백본(CLIP)으로 공정 재검증 ②
NT가 진짜 벽인지 ③ 벽이면 어떻게 뚫나**를 닫는다. 여기서도 성급한 선언 2개가 실험으로 정정됐다.

## 실험 10 — CLIP 배터리 (frozen B/16·L/14 + LN-tune)

**공정성 원칙(교훈 3):** "저수준이 안 된다"를 SBI로 반증했듯, "foundation이 NT 안 된다"도 CLIP의
*강한* 구성(L/14, LN-tune)으로 반증 시도해야 한다.

**최종 벤치마크 (LOMO cross-manip + in-dist, 5-fold ± std):**

| method | ConvNeXt | SRM | SBI | CLIP L/14 | CLIP LN-tune |
|---|---|---|---|---|---|
| Deepfakes | 0.824±.02 | 0.782 | 0.798±.02 | **0.923±.01** | 0.976*(in-dist) |
| Face2Face | 0.652±.02 | 0.652 | 0.534±.02 | 0.673±.02 | — |
| FaceSwap | 0.582±.04 | 0.524 | 0.644±.04 | **0.774±.02** | — |
| **NeuralTextures** | 0.549±.01 | 0.572 | 0.480±.02 | 0.556±.01 | 0.562±.003(LOMO) |
| **in-dist** | **0.929±.02** | 0.849 | — | 0.832 | 0.865 |

**판정 1 — 백본 이원화:** in-dist는 ConvNeXt(0.929)가 CLIP(frozen 0.832 / LN-tune 0.865)를 이김.
cross-manip은 CLIP L/14 압도. → **배포=ConvNeXt(특화), 일반화=CLIP(foundation).**

**판정 2 — FaceSwap "사각지대"는 약한 백본 탓이었다:** CLIP L/14가 FaceSwap 0.774. Part 1의
"FaceSwap이 탐지기를 무력화한다"는 서사 **폐기**. 강한 foundation이면 잘 잡음.

**판정 3 — NT는 진짜 벽 (공정 확정):** NT는 B/16 0.574 → L/14 0.556 → LN-tune 0.562로 **요지부동**.
백본 스케일(+DF 0.045, +FS 0.082)도 미세조정(in-dist FS 0.945까지 뽑는 강력함)도 **NT만 안 움직임**.
→ 모델 용량이 아니라 **정보 수준의 벽**. 4패러다임(외형·잔차·blending·foundation) 전부 NT ≤0.57.

## 실험 11 — NT temporal 돌파구 ⭐ 이 프로젝트의 핵심

**진단:** 시도한 4축이 전부 **단일프레임 공간 신호**. NT는 입 텍스처를 프레임마다 재생성 →
공간적으론 조용하나 **시간적으론 flicker**. 직교축 = 시간.

**실험:** 얼굴 크롭 연속프레임(~2프레임 간격, 원본 비디오 불필요)에서 **픽셀 시간특징 8개**(입/얼굴
프레임차, 입 텍스처 laplacian flicker, 입/얼굴 모션비) + LogReg. component split.

**결과:**

| method | spatial(CLIP L/14) | **temporal(pixel 8feat)** |
|---|---|---|
| Deepfakes | 0.923 | 0.729 |
| Face2Face | 0.673 | 0.707 |
| **FaceSwap** | **0.774** | **0.513** ← 시간축 무신호 |
| **NeuralTextures** | 0.556 | **0.777 ± .008** ← 시간축 강신호 |

우연 수준 → temporal은 **진짜 얼굴 동역학 조작**을 잡는 것(재연 계열 NT·F2F·DF↑, 정적 paste FaceSwap↓).
**공간(FaceSwap 담당) × 시간(NT 담당) 진짜 직교 상보성 확정.**

**문헌 확인:** NT 최난이도 = 문헌 동의. NT 최선책 = temporal/mouth(LipForensics "Lips Don't Lie",
CVPR2021). **내 진단이 문헌 SOTA 방향과 독립적으로 일치.** (단 둘 다 알려진 사실 → temporal 사용은
견고한 엔지니어링이지 새 알고리즘 아님. 졸업"작품"엔 충분, 차별점은 누수0 벤치마크+진단 설계.)

## Part 3 — 재연=시간 과평활 규명 & 과평활 aug 강건성 (독창 기여)

**질문:** NT(재연)를 temporal이 뚫는 "그 신호"의 **정체**는? 그리고 그걸 real-only로 합성해
미지 재연 일반화를 올릴 수 있나? (기존 temporal self-blend = STRD/VB는 시간 **교란/드리프트** 방향)

### 규명 (falsify-first, 반증 포함)
```
confound 검증: NT의 낮은 시간변동이 '입 움직임 감소'가 아니라 '텍스처 과평활'인가?
  → 광학흐름(Farneback) 모션보정 후 잔차 d_resid로 분리. NT는 d_resid에서 real보다 낮고
    분리력 AUC 0.762 > 모션 0.721 → 텍스처 과평활 확정(모션 무관). ✅ 각도 생존
Stage 1(고립특징): 과평활 vs 교란(STRD) vs warp-drift(VB) real-only 학습 → 실제 4기법 평가
  → 과평활만 NT 0.70, 교란/드리프트는 0.22/0.31(방향 반전). 깨끗한 dichotomy.
Stage 2(딥, 입-only): over_smooth NT 0.735 > spatial-SBI 0.677 > STRD=chance 0.500.
  → 딥모델에서도 과평활 방향이 재연을 가르고, 기존 self-blend 교란 방향은 chance.
```
**정직한 위치:** 일반적 "temporal self-blend"는 선행연구(STRD arXiv:2207.10402, VB 2408.17065).
**생존한 좁은 각도:** *재연=과평활*이며 기존 방향(교란/드리프트)과 **정반대**, 모션 통제로 실증.

### 과평활 aug의 가치 = "일반화 도구"이지 "in-dist 부스터" 아님 (반증 후 정정)
```
LOMO(leave-reenactment-family-out): swap만 지도학습, 재연 held-out
  A 지도(swap만)  재연 0.706 | B 지도+과평활aug  재연 0.733 | C real-only과평활  재연 0.644
  → B−A = +0.027, 그중 NT +0.052 (F2F +0.001). 이득이 과평활 지배기법(NT)에만 몰림 = 메커니즘 증거.
  → C: 진짜 fake 0개로도 NT 0.701 > A 0.678. real-only가 NT에선 swap지도 능가.
배포 재학습(4기법 전부 지도, in-dist): 과평활 aug 과용(frac=1.0) 시 오히려 −0.010(FS −0.021).
  → 진짜 라벨 있으면 합성 prior는 잉여+희석. aug는 in-dist 부스터 아님. (반증 수용)
aug 강도 스윕: frac{0,0.15,0.30,0.50} × {in-dist, LOMO}
  → frac=0.30이 sweet spot: in-dist −0.004(오차내 유지) & LOMO 재연 +0.044(NT +0.055).
```

### 배포 반영 = 앙상블 hedge (직접교체 기각 → 앙상블 채택)
```
배포크롭(0.50,0.96,0.16,0.84) 재학습, 동일 코드·시드:
  직접 교체 base→aug: in-dist −0.010 (FS −0.021 붕괴) → 기각 ✓
  앙상블 base3+aug3(6모델): in-dist +0.004 (NT +0.009, FS −0.002 무손상) → 채택 ✓
```
**배포 변경:** temporal 분기 = **6모델 앙상블**(3 표준 + 3 과평활-aug). in-dist NT 0.895→0.904,
swap 무손상, + LOMO로 입증된 미지-재연 일반화 강건성. (기존 3모델은 temporal_backup_*/에 백업.)

**독창 기여(정직·측정 근거):** ① 재연의 시간 서명을 '과평활'로 규명(모션 통제) — 기존 self-blend
교란 방향과 반대. ② 과평활 aug가 미지 재연 일반화를 올림(LOMO NT +0.055), 단 in-dist 부스터가
아니라 **강건성 도구**임을 반증 통해 정정. ③ 앙상블로 in-dist 무손실 + 강건성 배포 반영.
**한계:** 절대 이득 완만(+0.004~0.055), FaceSwap은 시간신호 없어 대상 아님(공간분기 몫).

### 캘리브레이션 (앙상블 점수이동 교정)
신규 6모델 앙상블은 AUC↑ 지만 점수분포가 위로 이동 → 고정 0.5 BACC↓ (Celeb 융합 0.719→0.549).
temporal 점수를 **FF++(학습분포)에서 leak-free로 Platt 보정**(a=0.714,b=-0.907), **Celeb-DF(미지)로 독립검증**:
```
FF++(fit)   temporal BACC@.5  0.731 → 0.812 (+0.081)   AUC 0.928 불변
Celeb(검증) 융합    BACC@.5  0.549 → 0.599 (+0.050)   AUC 0.801→0.808 (순위 보존)
```
Celeb에 맞추지 않고(반칙 방지) FF++ 보정이 미지 데이터로 전이됨. `models/temporal/calibration.json`,
infer.py `calib_temporal()`가 융합 전 temporal 점수에 적용.

## Part 4 — XAI (설명가능성) + 충실도 검증

"어디가 fake같은지" 시각화. 단, 히트맵은 '모델 주목 영역'이지 조작 물증이 아님 → **충실도를 측정**해 정직하게 표기.

### 시공간 Grad-CAM 충실도 (falsify-first)
정답 = FF++ 풀프레임 |fake−original| (픽셀정렬, 배경 diff≈0.6 → 정렬 확인). 재연(F2F,NT) 대상.
크롭 diff는 프레임별 독립 MTCNN이라 정렬 깨짐(입 8.5 < 나머지 24.1) → **풀프레임으로 교정**(반증→수정).
```
                pointing-game    CAM-vs-mask AUC
학습 6모델        0.516            0.706
랜덤가중치(sanity) 0.214            0.591     ← Adebayo sanity: 충실도가 학습에서 비롯
우연(chance)      0.200            0.500
```
→ 학습 CAM이 실제 조작영역을 우연의 2.6배로 국소화, 랜덤모델은 우연 수준 = **충실한 설명(학습에서 비롯)**.
과장 없음: pointing 0.516이라 절반은 빗나감. "우연의 2.6배로 유의 국소화"가 정확한 표현.

### 웹 통합 (app.py + xai.py)
`/api/predict`가 점수·판정 + **공간 Grad-CAM(얼굴)·시공간 Grad-CAM(입) 히트맵(base64)** + 브랜치 반응 서술 반환.
정직한 한계 표기 2가지:
- 히트맵 = "모델 주목 영역"(충실도 측정치 병기), 물증 아님.
- **브랜치 기반 계열판별(swap/재연)은 per-sample 신뢰 못 함** — 공간분기가 재연(NT)에도 강하게 반응(sp0.77>tp0.57).
  → family 텍스트를 '단정'에서 '브랜치 반응 서술 + 계열은 설계상 가설'로 낮춤(반증 수용).
